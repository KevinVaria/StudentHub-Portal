# StudentHub Requirements — Practical 1

## Project overview
StudentHub is a college portal for campus information and student services.

## Functional requirements
- Home page introduces the portal.
- About page explains the project.
- Register and Login pages provide forms.
- Dashboard and Profile pages represent student areas.
- Events page displays sample campus events.
- FAQ page lists common questions.
- Feedback page accepts comments.
- Contact page provides contact details and a message form.
- Admin page represents administration features.
- Every page has navigation to the other main pages.

## Non-functional requirements
- Semantic HTML5 elements are used where appropriate.
- Forms have visible labels.
- Pages have a viewport meta tag and meaningful title.
- Navigation and content are understandable and consistent.
- Future server-side functionality must validate input and enforce access control.

## Scope note
Practical 1 is planning documentation. It does not implement database storage, login authentication, or admin CRUD functionality; those are added in later practicals.
