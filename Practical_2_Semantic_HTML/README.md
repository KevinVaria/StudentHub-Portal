# StudentHub — Practical 2: Semantic HTML5 Pages

## Aim
To create the initial StudentHub portal pages using semantic HTML5 structure and links between pages.

## Pages included
- `index.html` — Home
- `about.html` — About StudentHub
- `register.html` — Registration form
- `login.html` — Login form
- `dashboard.html` — Student dashboard mock-up
- `events.html` — Campus events
- `profile.html` — Student profile mock-up
- `faq.html` — Frequently asked questions
- `feedback.html` — Feedback form
- `contact.html` — Contact details/form
- `admin.html` — Admin mock-up

## How to run
1. Extract the project ZIP.
2. Open `Practical_2_Semantic_HTML/index.html` in a browser.
3. Use the navigation links to open each page.

## Semantic elements
The pages use HTML5 elements such as `header`, `nav`, `main`, `section`, and `footer`, plus form labels where forms are present.

## Note
This practical is a static HTML prototype. Form submission, responsive styling, client-side validation, database access, and secure authentication are implemented in later practicals.
