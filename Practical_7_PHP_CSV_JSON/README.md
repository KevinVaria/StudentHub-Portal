# StudentHub - Practical 7
PHP server-side form processing with validation, sanitization and CSV/JSON storage.

## Run
Use XAMPP/WAMP/Laragon and put this folder inside the web root.
Then open:
`http://localhost/Practical_7_PHP_CSV_JSON/`

The registration form posts to `register.php`. Records are stored in `data/students.csv` and `data/students.json`.
